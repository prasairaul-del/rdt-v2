Four Agents
FilePicker → Planner → Editor → Reviewer
Spec §10, §15 3 sessions
▾
  • Define AgentInput / AgentOutput types (§10.1)
  • File Picker: returns FileSelection JSON, no direct FS access
  • Planner: returns Plan with steps, risks, testPlan
  • Editor: apply_patch only, inspect diff after every edit
  • Reviewer: must use smart_reasoning minimum — runs tests, reviews diff
  • Prompt standards from §15 for each agent
  • Output schema validation — reject malformed responses
✓ Acceptance criteria
✓ Each agent works with mock provider
✓ No direct filesystem calls from agents
✓ Malformed model output handled gracefully

  • Edit/review loop — max 3 passes
  • Save task log to .rdt/tasks/<id>.json

  • Generate final report with provider usage summary

✓ Full fixture task passes end-to-end
✓ Failed tasks produce readable report
✓ Task log saved with git diff inside

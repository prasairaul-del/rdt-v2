RDT v2 Architecture

Terminal-first AI coding assistant - clean rebuild focused on reliable repository editing

Core Principles

  • • Terminal-first design
  • • Single deterministic task runner
  • • No dashboards in MVP
  • • SQLite for storage

Workflow

  • • Load instructions → Scan repo → Pick files
  • • Plan → Edit → Run tests
  • • Review diff → Report
  • • All steps logged & inspectable

Agent Orchestration

  • • File Picker: selects relevant files
  • • Planner: creates step-by-step plan
  • • Editor: applies patches
  • • Reviewer: checks diff & tests
